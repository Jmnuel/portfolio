# Jhon Manuel Igdalino — Portfolio

Personal portfolio of Jhon Manuel Igdalino, AI Engineer and full-stack web & mobile developer from Catbalogan City, Samar, PH.

**Live:** https://jmanueligdalino.vercel.app

## Stack

- [Next.js 16](https://nextjs.org) (App Router) + React 19 + TypeScript
- [React Three Fiber](https://r3f.docs.pmnd.rs) + three.js for the particle "neural core" hero
- Tailwind CSS 4, [Motion](https://motion.dev), [Lenis](https://lenis.darkroom.engineering) smooth scroll
- Vercel Analytics and Speed Insights

## Editing content

All copy, links, projects, experience and stack live in [`lib/content.ts`](lib/content.ts).
Project screenshots are in `public/projects/`.

## Develop

```bash
npm install
npm run dev
```

Pushes to `main` deploy to production on Vercel; other branches get preview URLs.
